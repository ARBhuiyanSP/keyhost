Keyhost Homes Documentation & User Manual

Complete Operational Step-by-Step Manual for Guests, Property Owners, and System Administrators • Updated on

1. System Overview

Keyhost is a premium, fully automated multi-vendor booking and property management engine. It enables property owners (hosts) to manage their properties and receive payments, while guests can search, book, and pay for stays securely.

The platform automates the complete lifecycle of reservation, host approvals, payments, check-in management, billing, and cancellations.

Key Technology integrations: SSLCommerz Card Payment, bKash Checkout (Tokenized), real-time WhatsApp & SMS notifications, iCal calendar synchronization, and automated HMS accounts ledger syncing.

2. User Roles & Scope

Guest (Customer / Traveler) Guest

Can browse properties, register, request stays, book online via mobile banking/cards, track reward points, communicate with owners, and submit reviews.

Property Owner (Host) Host / Owner

Manages individual rooms/units or entire properties. Can add listings via a multi-step form, handle bookings on the interactive calendar, log manual walk-in reservations, generate guest payment links, request earnings payouts, and sync calendars via iCal.

Administrator Admin

Governs the entire platform. Approves listings, processes online refunds, manages global system configurations, verifies host payouts, sets commission rates, and reviews settings for general, SMS, email, and payment gateways.

3. Owner Host Management System (HMS) Suite (Detailed)

The Host Management System (HMS) provides a detailed, comprehensive software suite for hosts to automate hotel, flat, or resort unit operations. Below is a detailed operational guide for each sub-module.

HMS Central Calendar (Room Matrix & Grid View)

The HMS Calendar is an interactive timeline grid layout showing rooms/units on the vertical axis and days of the month on the horizontal axis.

  • Visual Coding: Reservations are color-coded based on their booking status (e.g., green for checked-in, orange for confirmed, gray for checked-out, purple for monthly long stays).
  • Drag-Select Reservations: Click and drag across dates in a specific room's row to trigger a walk-in booking instantly, with dates pre-filled.
  • Unassigned Row: A designated top row shows bookings that have not yet been assigned to a specific room, allowing hosts to drag and drop them to assign rooms.
  • Room Navigation: Centralized property selector dropdown, filter rooms by type, and navigate between months or days with left/right buttons.

Reservations & Walk-In Bookings

Manage bookings generated online or logged manually on-desk:
• Create Reservation: Select check-in/out dates. The system fetches available rooms for those dates. Set guest name, phone, email, number of guests, and booking source.
• Modifications: Add nights, shorten stays, change room numbers, or transfer guests to another room. The system recalculates room price balances and adjusts room status records automatically.

Guests CRM & Identity (KYC) Management

A central customer database built into the HMS:
• Guest Records: Track previous check-ins, guest emails, phone numbers, and special requests (e.g., extra pillows, late check-out).
• KYC Verification: Scan and upload images of guest NID (National ID) cards or passport photos directly into the guest detail panel. This provides instant security clearance and record availability during checkout.

Food & Beverage (F&B) POS Module

Manages in-house restaurant, cafe, or room-service dining orders:

  • Menu Customization: Hosts configure items (e.g., breakfast combos, coffee, soft drinks), categories, descriptions, and pricing.
  • Order Logging: Select room number, add food items, adjust quantities, and place the order.
  • Billing Settle Methods: Settle the F&B bill immediately as cash/card payment, or add it to the guest's master room bill to pay during final checkout.

Housekeeping & Room Turnovers

Keeps physical rooms clean and coordinates cleaning staff:

  • Room States: Rooms are automatically marked Dirty upon check-out or checkout time limit. Cleaners sweep the rooms and toggle them back to Clean.
  • Staff Ticketing: Create housekeeping tickets, assign them to specific employees (cleaners), and track progress (Pending, In Progress, Completed).

HMS Maintenance & Ticketing

Ensures room quality and minimizes unit downtime:
• Issue Reporting: Report physical failures (e.g., broken geyser, faulty lock, damaged lightbulb) specifying severity and description.
• Auto-Block Rooms: The system disables dirty or damaged rooms on the calendar, preventing booking requests or reservation allocations until the ticket is marked resolved.

Staff & Employee Management

Create separate credentials for staff members:
• Roles: Assign roles such as Receptionist, Housekeeper, Chef, Manager, or Admin.
• Permission Gates: Receptionists can create bookings and take bills but cannot alter room base rates. Managers can request payouts and adjust configurations.

HMS Pricing, Weekend & Seasonal Rates

Override baseline prices to match market demand:
• Configure weekend rates (Friday & Saturday) to apply price markups automatically.
• block out special dates or holidays and define fixed rate overrides for specific units.

4. Admin Operations & Governance Suite

The operational cockpit for Admin controls and financial accountability.

General Ledger & Platform Accounting

The Accounting module tracks the system's ledger, showing a double-entry balance sheet:
• Revenues: Visual summaries of commission margins collected from completed bookings.
• Expenses: Platform host payouts, transaction processing fees, and running operational expenses.

Coupon & Promo Engine

Create promotional discount codes (e.g., WELCOME10, EID2026):
• Set discounts as flat BDT amounts or percentage-based deductions.
• Configure usage limits (per user or globally) and set strict start/end expiry dates.

Review Moderation & Approvals

Review submittals are queued for Admin audit to prevent spam or abusive language:
• Admin can approve, reject, or delete submitted guest reviews.
• In Settings, Admin can toggle Auto-Approve Reviews if direct moderation is not desired.

Security Deposit Management

For properties requiring security deposits (to protect hosts against damages):
• Track deposits collected during booking.
• Release the deposit holding to the guest after checkout, or log deductions for reported room damages.

Loyalty Rewards Setup

Manage the platform's customer retention rewards:
• Set point earning factor (e.g. 1 point awarded per 100 BDT spent).
• Define point redeem value (e.g. 1 point = 1 BDT discount).

Customer Support Panel

Provides a central queue of questions submitted via the public contact form. Admins can view message threads and send email replies directly from the panel.

5. Guest Process Flow (Step-by-Step)

A seamless, secure workflow from search to checkout and post-stay feedback.

1

Search & Filtering

Guest enters the destination, check-in/out dates, and number of guests on the home page search bar. The system shows available properties, which can be filtered by price, ratings, and features.

2

Booking Request Submission

After selecting a property and verifying the nightly price, the guest clicks "Request to Book". The booking is placed in a Pending status, and the Host is instantly notified.

3

Host Approval & Accept State

Once the host reviews and accepts the booking, the booking status transitions to "Request Accepted". The guest receives a WhatsApp/SMS alert with the booking details and payment time limit (default: 30 minutes).

4

Making Secure Payment

Guest goes to My Bookings > Make Payment in their dashboard. They select their preferred gateway:
• bKash: Redirects to tokenized checkout where they input their PIN.
• SSLCommerz: Redirects to card, mobile banking (Nagad, Rocket), or net banking.

5

Booking Confirmation & Rewards

Upon successful payment, the gateway redirects back to Keyhost. The status upgrades to "Confirmed". The guest is awarded loyalty reward points based on the transaction amount, which can be redeemed for discounts on subsequent bookings.

6

Stay, Checkout, and Reviews

After staying at the property, the guest checks out. They can visit their dashboard to write a rating and review for the property, contributing to its public rating score.

6. Host (Owner) Process Flow (Step-by-Step)

Comprehensive property management, walk-in guests, billing, and financials.

1

Host Registration & Verification

User registers as a Host on the platform, completes their business profile (company name, address, tax details), and gains access to the Host Management System (HMS).

2

Listing Property via 6-Step Wizard

Hosts add properties through the listing creation wizard:
• Step 1: Title, Description, Property Type.
• Step 2: Address and Map Coordinates.
• Step 3: Rooms, Bathrooms, Max Guest Capacity.
• Step 4: Checkbox grid of amenities (WiFi, Pool, AC, Kitchen).
• Step 5: Upload high-res images (drag & drop).
• Step 6: Set nightly price and submit for Admin review/approval.

3

Interactive Calendar & Walk-In Bookings

Hosts use the graphical HMS Calendar to manage room inventory. If a guest arrives offline (Walk-in), the host selects the dates directly on the calendar, inputs guest details, selects the room, and confirms the manual booking.

4

Billing, Extra Charges & Payment Links

For manual bookings, hosts can record payments:
• Cash Payment: Logged as manual cash, generating an offline payment ledger entry.
• Online Payment Link: Generates a secure URL. Guest scans the QR code or clicks the link to pay online via bKash/SSLCommerz.
• Extra Bills: Log food, laundry, or damages to the invoice. All bills must be settled before checkout.

5

Cancellation & Refund Rules

• If a booking with an offline/cash payment is cancelled, the system automatically marks the refund as "Completed".
• If the booking was paid online, the host cannot refund directly; the refund goes to the Admin queue as "Pending" to process the gateway transaction safely.

6

iCal Calendar Sync & Payout Requests

Hosts can import/export iCal links to sync availability with Airbnb and Booking.com. Earnings (minus system commissions) accumulate in the Host Wallet, from which they can request payouts directly to their bank accounts once the minimum balance is met.

7. Admin Process Flow (Step-by-Step)

Platform monitoring, system controls, transaction gateways, and reporting.

1

System Configuration & Gateway Switches

Admin sets up site branding, logos, SEO, and social handles in the Settings Hub. Admin manages API credentials for bKash, SSLCommerz, and Nagad, toggling between Sandbox (Testing) and Live (Production) environments.

2

Listing Verifications

When a host submits a new property, it goes into a pending review state. Admin inspects the images, description, pricing, and approves/publishes the listing to the guest-facing website.

3

Gateway Payouts & Commission Rates

Admin defines global or host-specific commission rates (e.g. 10%). When hosts submit a payout request, Admin reviews their ledger, deducts the platform fee, transfers the money, and marks the request as "Paid".

4

Refund Queue Management

Admin monitors all online refund requests in the admin panel. When Admin clicks "Approve Refund", the backend calls the respective gateway (bKash/SSLCommerz) APIs to automatically refund the money to the guest's MFS wallet or bank account.

5

Communication Channels & Audit Logs

Admin configures default SMTP email relays and links WhatsApp/SMS gateways. All transaction logs and token flows are written to the database and logs (like bkash_tokens.txt and whatsapp.log) for continuous audit and troubleshooting.

8. Developer & Maintenance Information

Attention Maintenance Developers: Ensure to run the database migration scripts (like migration_live.sql) on the production database before pushing any backend updates to prevent missing settings fields.
  • Local Cache: Settings state is cached using Zustand persist middleware under the key 'settings-storage'. Hard refresh the browser page if any setting does not reflect instantly.
  • Token Logging: bKash API requests, responses, and errors are logged under backend/bkash_tokens.txt. Use this log to verify gateway communication status.
  • WhatsApp Logger: Baileys connections are logged under backend/whatsapp.log. Check this file for connection errors like WhatsApp's 405 WebSocket blocks.
