Local PC তে Preparation

Hosting এ কিছু upload করার আগে এই কাজগুলো local এ করতে হবে

1
📦 Frontend — Production .env তৈরি করুন

কোথায় করবেন: আপনার PC তে frontend/ folder এ

কী করবেন: .env.production নামে একটা নতুন file তৈরি করুন এবং নিচের line টা লিখুন:

.env.production
REACT_APP_API_URL=https://api.tradfly.com/api
ℹ️
কেন দরকার?
Development এ frontend localhost:5000 এ API call করে। Production এ এটা api.tradfly.com এ call করবে। এই file টা দিয়ে React কে বলছি কোথায় API পাবে।
2
🔨 React Production Build তৈরি করুন

কোথায় করবেন: Terminal / Git Bash এ

bash 
# frontend folder এ যান
cd D:/88i/booking-systme/frontend

# production build তৈরি করুন
npm run build

কতক্ষণ লাগবে: ২-৫ মিনিট। শেষ হলে frontend/build/ folder তৈরি হবে।

✅
সফল হলে দেখবেন:
"The build folder is ready to be deployed." এই message আসবে।
❌
Error হলে:
আগে npm install run করুন, তারপর আবার npm run build করুন।
3
🗄️ Local Database Export করুন

কোথায় করবেন: Git Bash এ

bash 
mysqldump -u root keyhost_booking_system > tradfly_database.sql

এই command টা আপনার project folder এ tradfly_database.sql নামে একটা file তৈরি করবে। এটা hosting এ import করতে হবে।

⚡
Password থাকলে:
mysqldump -u root -p keyhost_booking_system > tradfly_database.sql লিখুন — password চাইবে।
4
⚙️ Backend Production .env আপডেট করুন

কোথায় করবেন: backend/.env file open করুন এবং নিচের মতো করে সব values আপডেট করুন।

⚠️ এই file টাই hosting এ upload করতে হবে — তাই আপডেট করে রাখুন:

backend/.env (production)
# ===== Database (cPanel MySQL থেকে নিন) =====
DB_HOST=localhost
DB_USER=tradfly_khuser         # cPanel এ তৈরি করা user
DB_PASSWORD=YOUR_STRONG_PASSWORD  # cPanel এ set করা password
DB_NAME=tradfly_keyhost          # cPanel এ তৈরি করা database
DB_PORT=3306

# ===== JWT (random string দিন — min 64 char) =====
JWT_SECRET=tradfly2026_very_long_random_secret_key_change_this_now_xyz
JWT_EXPIRES_IN=7d
JWT_REFRESH_SECRET=tradfly2026_refresh_secret_also_long_random_key_abc
JWT_REFRESH_EXPIRES_IN=30d

# ===== Server =====
PORT=3001
NODE_ENV=production

# ===== Domain =====
FRONTEND_URL=https://tradfly.com

# ===== Email =====
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_gmail_app_password

# ===== SSLCommerz Payment =====
SSLCOMMERZ_STORE_ID=your_store_id
SSLCOMMERZ_STORE_PASSWORD=your_store_password
SSLCOMMERZ_IS_LIVE=true

# ===== Google OAuth (existing values রাখুন) =====
GOOGLE_CLIENT_ID=your_existing_google_client_id
GOOGLE_CLIENT_SECRET=your_existing_google_client_secret
🔒
গুরুত্বপূর্ণ!
.env file কখনো GitHub এ push করবেন না। .gitignore এ .env আছে কিনা confirm করুন।
2

cPanel — MySQL Database Setup

tradfly.com hosting এ database তৈরি করুন এবং data import করুন

5
🌐 cPanel Login করুন

Browser এ যান: https://tradfly.com/cpanel অথবা Namecheap dashboard থেকে cPanel login করুন।

URL হবে এরকম: https://server123.namecheaphosting.com:2083

6
🗄️ MySQL Database তৈরি করুন

cPanel → "MySQL Databases" section এ যান:

  1. Create New Database section এ type করুন: keyhost → Create Database click করুন
    → Full name হবে: tradfly_keyhost (cPanel username automatically prefix করে)
  2. Create New User section এ:
    • Username: khuser
    • Password: strong password দিন (Password Generator ব্যবহার করুন) — password টা নোট রাখুন!
    • Create User click করুন
  3. Add User To Database section এ:
    • User: tradfly_khuser select করুন
    • Database: tradfly_keyhost select করুন
    • Add click করুন
    • Next page এ ALL PRIVILEGES checkbox tick করুন → Make Changes
ℹ️
Prefix সম্পর্কে জানুন
Namecheap এ cPanel username যদি tradfly হয়, তাহলে আপনি keyhost দিলে database name হবে tradfly_keyhost। এই full name টাই backend .env এ দিতে হবে।
7
📥 Database Import করুন (phpMyAdmin)

cPanel → phpMyAdmin এ যান:

  1. Left panel এ tradfly_keyhost database click করুন
  2. উপরে Import tab click করুন
  3. Choose File button click করুন → আপনার tradfly_database.sql file select করুন
  4. নিচে scroll করে Go button click করুন
  5. কিছুক্ষণ wait করুন (file size এর উপর নির্ভর করে)
✅
সফল হলে:
"Import has been successfully finished" message দেখাবে। Left panel এ tables দেখা যাবে।
⚡
File বড় হলে:
phpMyAdmin এ file size limit থাকতে পারে। বড় file এর জন্য cPanel Terminal এ: mysql -u tradfly_khuser -p tradfly_keyhost < tradfly_database.sql

Backend Upload ও Node.js App Setup

api.tradfly.com এ Node.js server চালু করা

8
📁 nodeapp Folder তৈরি ও Files Upload

cPanel → File Manager এ যান:

  1. Left এ /home/yourusername/ এ click করুন (public_html এর বাইরে)
  2. উপরে + Folder button click করুন → name দিন: nodeapp → Create
  3. nodeapp folder এ enter করুন
  4. উপরে Upload button click করুন

কী upload করবেন:

nodeapp/ ├── server.js ✅ upload ├── package.json ✅ upload ├── package-lock.json ✅ upload ├── .env ✅ upload (production values সহ) ├── routes/ ✅ upload (পুরো folder) ├── config/ ✅ upload ├── middleware/ ✅ upload ├── utils/ ✅ upload ├── uploads/ ✅ empty folder তৈরি করুন └── node_modules/ ❌ upload করবেন না!
💡
সহজ উপায় — Zip করে Upload:
  1. Windows Explorer এ backend/ folder open করুন
  2. node_modules folder বাদে সব select করুন (Ctrl+A, তারপর Ctrl+Click করে node_modules deselect করুন)
  3. Right click → Send to → Compressed (zipped) folder
  4. cPanel File Manager এ nodeapp/ folder এ zip upload করুন
  5. Uploaded zip file এ Right click → Extract
9
🌐 Subdomain তৈরি — api.tradfly.com

cPanel → Domains → Subdomains এ যান:

Field Value Note
Subdomain api শুধু "api" লিখুন
Domain tradfly.com Dropdown থেকে select করুন
Document Root /home/yourusername/nodeapp Auto-fill হবে, /nodeapp যোগ করুন

Create button click করুন।

ℹ️
Document root automatically /home/yourusername/public_html/api দিতে পারে। সেটা মুছে /home/yourusername/nodeapp লিখুন।

⚙️ Node.js Application তৈরি করুন

cPanel → Software → Setup Node.js App এ যান:

উপরে "CREATE APPLICATION" button click করুন। নিচের values দিন:

Setting Value

Application mode Production
Application root nodeapp
Application URL api.tradfly.com
Application startup file server.js

CREATE button click করুন।

11
📦 npm install চালান

App তৈরি হলে "Run NPM Install" button দেখবেন — সেটা click করুন।

অথবা cPanel → Terminal এ:

bash 
cd ~/nodeapp
npm install --omit=dev

এটা ২-১০ মিনিট সময় নিতে পারে। সব dependencies install হবে।

Status ● Running দেখালে সফল।

এখনই Test করুন: Browser এ যান:

URL 
https://api.tradfly.com/api/health
✅
সফল Response:

❌
Error হলে:

Frontend Deploy — tradfly.com

React build public_html এ রাখা এবং routing configure করা

14
📤 React Build public_html এ Upload করুন

cPanel → File Manager → public_html/ folder এ যান।

যদি আগে থেকে কিছু থাকে (index.html, cgi-bin ইত্যাদি), সেগুলো delete করুন।

Upload করার উপায়:

  1. Local frontend/build/ folder এর সব কিছু select করুন
  2. Zip করুন → build.zip
  3. cPanel File Manager এ public_html/ তে upload করুন
  4. Upload শেষে build.zip এ Right click → Extract → Extract to /public_html/
  5. Extract হলে build.zip delete করুন

শেষে public_html/ এ এইগুলো থাকবে:

public_html/ ├── index.html ✅ থাকবে ├── static/ ✅ থাকবে │ ├── css/ │ ├── js/ │ └── media/ ├── manifest.json ✅ থাকবে ├── robots.txt ✅ থাকবে └── favicon.ico ✅ থাকবে
⚠️
সাবধান!
build/ folder নিজে upload করবেন না। build/ এর ভেতরের contents upload করতে হবে। নইলে URL হবে tradfly.com/build/ যেটা wrong।
15
📝 .htaccess তৈরি করুন

cPanel → File Manager → public_html/ এ যান।

উপরে + File click করুন → name দিন .htaccess → Create

File এ Right click → Edit করুন এবং নিচের code paste করুন:

public_html/.htaccess
Options -MultiViews
RewriteEngine On

# React Router: সব route index.html এ redirect করুন
# (page refresh হলে 404 না দিয়ে React handle করবে)
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.html [QSA,L]

Save করুন।

ℹ️
এই file না থাকলে page refresh করলে 404 error আসবে। React Router এর জন্য এটা অবশ্যই দরকার।
16
🔍 Google OAuth Redirect URI আপডেট করুন

Project এ Google Login আছে। Production এ কাজ করতে হলে Google Console এ tradfly.com add করতে হবে।

  1. console.cloud.google.com এ যান
  2. আপনার project select করুন
  3. APIs & Services → Credentials → আপনার OAuth Client
  4. Authorized JavaScript origins এ add করুন: https://tradfly.com
  5. Authorized redirect URIs এ add করুন: https://tradfly.com
  6. Save করুন

Payment gateway production এ কাজ করতে:

  1. SSLCommerz merchant panel এ login করুন

  3. Backend .env এ SSLCOMMERZ_IS_LIVE=true নিশ্চিত করুন
  4. Backend Node.js App restart করুন (Setup Node.js App → Stop → Start)

Common Errors ও Solutions

সমস্যা হলে এখানে দেখুন

❌ App not starting
  • cPanel → Setup Node.js App → Error Log দেখুন
  • .env এর DB_NAME বা DB_PASSWORD ভুল কিনা check করুন
  • npm install পুরোপুরি হয়েছে কিনা দেখুন
  • Node.js version mismatch? — 18.x select করুন
❌ 502 Bad Gateway
  • Node.js App Running status এ আছে কিনা দেখুন
  • Subdomain document root সঠিক আছে কিনা দেখুন (/home/user/nodeapp)
  • App stop করে আবার start করুন
❌ Page refresh এ 404
  • public_html/.htaccess file আছে কিনা দেখুন
  • File Manager এ hidden files show করুন (Settings → Show Hidden Files)
  • Content সঠিক আছে কিনা দেখুন
❌ CORS Error / API fail
  • Backend .env এ FRONTEND_URL=https://tradfly.com আছে কিনা
  • Browser Console → Network tab এ request URL দেখুন
  • Backend app restart করুন
❌ Image upload fail
  • ~/nodeapp/uploads/ folder exist করে কিনা
  • Permission: chmod -R 755 ~/nodeapp/uploads
❌ Database connection fail
  • .env এ DB_NAME, DB_USER, DB_PASSWORD সঠিক আছে কিনা
  • cPanel MySQL এ user টা database এ All Privileges এ add আছে কিনা
