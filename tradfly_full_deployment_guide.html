🚀 tradfly.com Deployment Guide

Complete Step-by-Step Documentation for Namecheap Shared Hosting with cPanel

Stack: React.js Frontend, Node.js + Express Backend, MySQL Database

Architecture Plan:
• Frontend: tradfly.com (Hosted in public_html/ folder)
• Backend API: api.tradfly.com (Hosted in nodeapp/ folder)

📌 Phase 1: Local Preparation (আপনার পিসিতে)

1 Frontend: Update Environment & Build

Local project-এ frontend-এর production environment file তৈরি করে build করতে হবে।

১. frontend/ ফোল্ডারে .env.production নামে একটি ফাইল তৈরি করুন এবং নিচের কোড দিন:

frontend/.env.production 
REACT_APP_API_URL=https://api.tradfly.com/api

২. Terminal (Git Bash / VS Code terminal) ওপেন করে frontend ফোল্ডারে যান এবং build করুন:

Terminal 
cd frontend
npm run build

✅ এই কমান্ডটি শেষ হলে frontend/build/ নামে একটি ফোল্ডার তৈরি হবে।

2 Backend: Prepare Production .env

Hosting-এ আপলোড করার জন্য backend/.env ফাইলটি production values দিয়ে আপডেট করুন:

backend/.env 
# Database (These will be from cPanel, change accordingly)
DB_HOST=localhost
DB_USER=tradfly_khuser
DB_PASSWORD=YOUR_CPANEL_DB_PASSWORD
DB_NAME=tradfly_keyhost
DB_PORT=3306

# Security JWT (use long random strings)
JWT_SECRET=tradfly_random_long_secret_string_for_production_use_only
JWT_EXPIRES_IN=7d
JWT_REFRESH_SECRET=another_random_long_secret_string_for_refresh_token
JWT_REFRESH_EXPIRES_IN=30d

# Server & URLs
PORT=3001
NODE_ENV=production
FRONTEND_URL=https://tradfly.com

# Email Config
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_app_password

# SSLCommerz & Keys (Keep your existing values but turn on live mode)
SSLCOMMERZ_STORE_ID=your_store_id
SSLCOMMERZ_STORE_PASSWORD=your_store_password
SSLCOMMERZ_IS_LIVE=true

3 Extract/Export Database

আপনার লোকাল ডাটাবেসটি export করে একটি .sql ফাইল তৈরি করুন:

Terminal 
mysqldump -u root keyhost_booking_system > tradfly_database.sql

✅ এই tradfly_database.sql ফাইলটি পরবর্তীতে cPanel-এ আপলোড করতে হবে।

📌 Phase 2: Database Setup (cPanel)

4 Create MySQL Database & User

  1. Namecheap cPanel-এ লগইন করুন।
  2. MySQL Databases অপশনে যান।
  3. Create New Database: keyhost লিখে Create Database করুন। (cPanel নিজে থেকে username prefix অ্যাড করে নাম বানাবে tradfly_keyhost)।
  4. Add New User: Username দিন khuser, Password Generator দিয়ে একটি শক্ত পাসওয়ার্ড দিন এবং পাসওয়ার্ডটি সেভ করে রাখুন (backend .env-এ বসানোর জন্য)। Create User-এ ক্লিক করুন। (ইউজারনেম হবে tradfly_khuser)।
  5. Add User To Database: User এবং Database সিলেক্ট করে Add করুন। এরপর ALL PRIVILEGES বক্সে টিক দিয়ে Make Changes এ ক্লিক করুন।

5 Import SQL Data

  1. cPanel এর হোমপেজে ফিরে গিয়ে phpMyAdmin ওপেন করুন।
  2. বাম পাশের লিস্ট থেকে আপনার তৈরি করা ডাটাবেস (tradfly_keyhost) সিলেক্ট করুন।
  3. উপরের মেনু থেকে Import এ ক্লিক করুন।
  4. Choose File এ ক্লিক করে আপনার পিসির tradfly_database.sql ফাইলটি সিলেক্ট করুন।
  5. নিচে গিয়ে Go বাটনে ক্লিক করুন। "Import has been successfully finished" লেখা আসলে কাজ শেষ।

📌 Phase 3: Backend Deployment (App Setup)

6 Create Subdomain for API

  1. cPanel-এ গিয়ে Subdomains / Domains অপশনে যান।
  2. Subdomain: api
  3. Domain: tradfly.com
  4. Document Root: বক্সে /nodeapp দিন (অর্থাৎ /home/yourusername/nodeapp)।
  5. Create এ ক্লিক করুন।

7 Upload Backend Files

  1. cPanel-এর File Manager এ যান।
  2. আপনার হোম ডিরেক্টরিতে (public_html এর বাইরে) nodeapp নামে একটি ফোল্ডার তৈরি করুন।
  3. আপনার লোকাল backend/ ফোল্ডারটি ওপেন করে node_modules/ বাদ দিয়ে বাকি সব ফাইল সিলেক্ট করে একটি .zip ফাইল তৈরি করুন।
  4. cPanel File Manager-এ nodeapp ফোল্ডারের ভিতরে ঐ .zip ফাইলটি আপলোড করুন।
  5. আপলোড শেষে zip ফাইলটি Extract করুন।
/home/yourusername/nodeapp/
├── package.json
├── server.js
├── .env (Production values)
├── routes/
├── config/
├── models/ (If any)
├── middleware/
└── utils/
বিঃদ্রঃ: node_modules ফোল্ডার কখনোই আপলোড করবেন না। এটি হার্ডড্রিভের অনেক জায়গা নেয় এবং লিনাক্স সার্ভারে ইন্সটল করতে হয়।

8 Setup Node.js App in cPanel

  1. cPanel থেকে Setup Node.js App অপশনে যান।
  2. Create Application বাটনে ক্লিক করুন।
Field Value
Node.js version 18.x বা তার উপরের লেটেস্ট ভার্সন
Application mode Production
Application root nodeapp
Application URL api.tradfly.com
Application startup file server.js

Create এ ক্লিক করুন।

9 Install Packages & Start API

  1. Node app তৈরি হলে Run NPM Install বাটনে ক্লিক করুন। প্যাকেজ ইনস্টল হতে কয়েক মিনিট সময় লাগতে পারে।
  2. ইন্সটল সফল হলে অ্যাপটির START বাটনে ক্লিক করুন।

10 Set Uploads Permissions

আপনার cPanel Terminal অপশনটি ওপেন করুন এবং নিচের কমান্ডগুলো রান করুন:

Terminal 
cd ~/nodeapp
mkdir -p uploads/properties uploads/avatars uploads/documents
chmod -R 755 uploads/

✅ Backend ঠিকমতো চললে ব্রাউজারে https://api.tradfly.com/api/health গেলে {"success":true,"message":"Keyhost Homes API is running"} দেখাবে।

📌 Phase 4: Frontend Deployment

11 Upload React Build Folder

  1. cPanel File Manager থেকে public_html ফোল্ডারে যান।
  2. সেখানে থাকা ডিফল্ট ফাইলগুলো (যেমন cgi-bin বাদে অন্য কোন .html থাকলে) ডিলেট করুন।
  3. আপনার লোকাল পিসিতে frontend/build/ ফোল্ডারের ভিতরের সব কন্টেন্ট সিলেক্ট করে একটি .zip ফাইল বানান। (খেয়াল রাখবেন build ফোল্ডারটি zip না করে ভিতরের ফাইলগুলো zip করবেন)।
  4. cPanel-এ public_html ফোল্ডারে সেটি আপলোড করে Extract করুন।
/home/yourusername/public_html/
├── index.html
├── manifest.json
├── robots.txt
└── static/

12 Create .htaccess for React Router

React SPA (Single Page Application)-এ সরাসরি লিঙ্কে গেলে 404 Error যেন না আসে, তাই public_html ডিরেক্টরিতে .htaccess ফাইল তৈরি করে নিচের কোডটি দিতে হবে:

  1. File Manager-এর public_html ফোল্ডারে +File এ ক্লিক করে ফাইলের নাম দিন .htaccess।
  2. ফাইলটি Edit করে নিচের কোড পেস্ট করে Save করুন:
public_html/.htaccess 
Options -MultiViews
RewriteEngine On

# React Router Configuration
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.html [QSA,L]

📌 Phase 5: Additional Validations

13 SSLCommerz Production Update

পেমেন্ট গেটওয়ের জন্য SSLCommerz-এর স্টোর প্যানেলে লগইন করে আপনার production ডোমেইন https://tradfly.com whitelisted করে IPN Settings-এ https://api.tradfly.com/api/sslcommerz/ipn (যদি আপনার এপিআই লজিক অনুযায়ী দরকার পড়ে) সেট করে নেবেন।

14 Google OAuth Console Update

Google Cloud Console-এ গিয়ে আপনার প্রজেক্টের Credentials -> OAuth 2.0 Client IDs এ যান:

  • Authorized JavaScript origins: https://tradfly.com এবং https://www.tradfly.com যুক্ত করুন।
  • Authorized redirect URIs: https://api.tradfly.com/api/auth/google/callback (বা আপনার রুট অনুযায়ী) যুক্ত করুন।

📌 Troubleshooting & Common Errors

Error / Issue Solution
502 Bad Gateway / Backend Error Setup Node.js App থেকে অ্যাপটি একবার STOP করে আবার START করুন। nodeapp/ এ থাকা .env তে ডাটাবেস পাসওয়ার্ড বা নাম ভুল আছে কিনা চেক করুন।
CORS Error on Frontend Server.js (Backend) ফাইলে cross origin allow করা আছে কিনা নিশ্চিত করুন। আপনার frontend.env.production এ API url সঠিক আছে কিনা দেখুন এবং re-build করুন।
404 Route Not Found on Refresh আপনার public_html/.htaccess ফাইলটি সঠিকভাবে তৈরি হয়নি অথবা সার্ভারে AllowOverride অন করা নেই (സാധാരണ Namecheap-এ অন থাকে)।

✅ Final Check: ব্রাউজারে https://tradfly.com ওপেন করুন। সবকিছু ঠিক থাকলে প্রজেক্টটি সুন্দরভাবে রান করবে।
