🚀 Keyhost24.com - Namecheap Deployment Guide

Complete Step-by-Step Guide for the Booking System Project

Phase 1: Local Preparation (Your PC)

1. Prepare the Backend

  • Open the backend/.env file on your computer.
  • Change the environment strictly for production: 
    NODE_ENV=production
FRONTEND_URL=https://keyhost24.com
PORT=5000
  • Zip the entire backend folder into a file named backend.zip. Do NOT include the `node_modules` folder inside your zip to save upload time.

2. Prepare the Frontend

  • Open your frontend/.env file and ensure you update your REACT_APP_API_URL if needed, but the current configuration is self-hosted so just proceed.
  • Open your terminal, go to your frontend folder, and run: 
    npm run build
  • After it succeeds, go inside the newly created frontend/build folder, select ALL the files, and Add to Archive to create frontend-build.zip.

Phase 2: Namecheap Database Setup

  • Log into your Namecheap cPanel.
  • Navigate to MySQL Databases.
  • Create a New Database (e.g., yourcpanelusername_keyhost).
  • Create a New User (e.g., yourcpanelusername_keyuser) and give it a strong password. Save this password somewhere safe!
  • Add the User to the Database and check the box that says All Privileges.
  • Next, go to phpMyAdmin in cPanel, select your newly created database on the left sidebar.
  • Click Import at the top, select your local Keyhost database SQL file, and press Go to import your local data into the live server.

Phase 3: Backend Setup (cPanel Setup Node.js App)

  • Go to File Manager in cPanel.
  • In the root directory (outside of `public_html`), create a new folder named keyhost-api.
  • Open keyhost-api, click Upload, and upload your backend.zip file. Then, right-click and extract it.
  • In cPanel, go to Setup Node.js App.
  • Click Create Application.
  • Set the Node.js version (preferably 18.x.x or higher).
  • Set the Application mode to Production.
  • Application root: keyhost-api/backend
  • Application URL: keyhost24.com/api
  • Application startup file: server.js
  • Click Create.
  • Once created, scroll down and click the Run NPM Install button and wait for it to successfully install everything.
  • Scroll up and click Stop App, then click Start App to ensure it grabs the fresh dependencies.

Phase 4: Backend Environment Variables (.env)

In your Setup Node.js App dashboard (where you just hit start/stop), scroll down to the Environment variables section.

Click "Add Variable" to add all of your database secrets here permanently in cPanel, instead of relying on the local .env file. Add the following:

  • DB_HOST = 127.0.0.1 (or localhost)
  • DB_USER = yourcpanelusername_keyuser
  • DB_PASSWORD = the_password_you_just_created
  • DB_NAME = yourcpanelusername_keyhost
  • FRONTEND_URL = https://keyhost24.com
  • NODE_ENV = production

Click Save, and restart the Node.js app once more to lock these variables into memory.

Phase 5: Frontend Hosting (public_html)

  • Navigate back to File Manager in cPanel.
  • Open the public_html folder.
  • If there is a default folder or files from Namecheap, delete everything so it is completely empty.
  • Click Upload and select your frontend-build.zip file.
  • Right-click the zip file and click Extract. Ensure the extraction path is exactly /public_html.
  • Delete the zip file to save space.
  • CRITICAL: Because React is a single-page app, you must tell the Apache server how to handle routing and the advanced caching mechanics we just set up. In `public_html`, find the .htaccess file (enable "Show Hidden Files" in Settings if you don't see it). Ensure its content has the routing fallback mechanics applied.

Phase 6: Verification & SSL

  • Go to Namecheap cPanel -> Namecheap SSL and make sure the free SSL is installed and active on keyhost24.com.
  • Open an incognito tab and test https://keyhost24.com.
  • Ensure the property images load, the property calendar populates correctly, and the login page functions properly.
  • To verify the API is connected successfully, you can visit https://keyhost24.com/api/health and ensure it returns JSON saying "Keyhost Homes API is running".
